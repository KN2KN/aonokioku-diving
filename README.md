# 蒼の記憶 — 海底遺跡ダイビング

Blenderで制作した海底遺跡を、一人称視点で探索する小さな3Dゲームです。

## 遊ぶ

https://kn2kn.github.io/aonokioku-diving/

3つの宝物を回収し、酸素が尽きる前に船のロープへ戻ってください。宝物は近づくと自動で回収されます。金色の輪が帰還地点です。

## 操作

- PC: WASD / ↑↓ で移動、画面ドラッグ / ←→ で見回す
- スマートフォン: 左スティックで移動、画面ドラッグで見回す
- Ⅱ / Esc: 一時停止
- 音 OFF / ON: 音を切り替え
- 画質: 自動・高画質・軽量を切り替え

## 動作環境

WebGLが利用できるブラウザが必要です。表示が重い場合は「画質：軽量」を選んでください。WebGLが無効なブラウザでは開始できません。

## ローカルで起動

ファイルを直接開かず、リポジトリのルートでHTTPサーバーを起動してください。Pythonがある場合:

```sh
python -m http.server 8000
```

その後 http://localhost:8000/ を開きます。ビルドやnpmパッケージのインストールは不要です。

## 構成

- `index.html`, `style.css`: 画面とレスポンシブUI
- `game.js`: ゲーム進行、入力、魚群などの演出
- `engine.js`: WebGL描画、GLB読み込み、影と水中表現
- `logic.js`: 移動、衝突、宝物、帰還判定
- `audio.js`: ブラウザ内で生成する環境音
- `assets/underwater-ruins.glb`: Blenderから書き出した遺跡モデル
- `assets/world3d.json`: 宝物、帰還地点、衝突情報

GitHub Pagesは `main` ブランチのルートから配信します。ゲーム本体は外部CDNや外部音声ファイルに依存しません。
